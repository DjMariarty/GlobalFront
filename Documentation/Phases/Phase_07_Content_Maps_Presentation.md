# Phase 07 — Content + Maps + Presentation

> Status: planned

## Goal

Довести карты, graphics, UI, audio, VFX, destruction и presentation до production scope 1.0.

## Dependencies

- M3 Five Factions;
- применимый M4 AI;
- утверждённые art/UI/audio directions;
- production content pipeline и лицензионные правила.

## Scope

- полноценные карты для 1v1–5v5 и FFA;
- graphics;
- UI;
- audio;
- VFX;
- destruction;
- polish.

## Key Systems

- map authoring/validation;
- content and asset pipeline;
- rendering and visual presentation;
- player UI/UX;
- audio/VFX/destruction presentation;
- localization/accessibility scope — TBD / Owner Decision Required.

## Milestones

- полный утверждённый map set;
- production presentation baseline;
- validated 5v5 map approach.

## Acceptance Criteria

- карты поддерживают утверждённые modes 1v1–5v5 и FFA;
- 5v5 maps имеют сопоставимые starts, равномерные resources и balanced starting economy;
- maps поддерживают большие армии и долгие матчи;
- graphics/UI/audio/VFX/destruction соответствуют approved production direction;
- внешние assets имеют подтверждённые licenses.

## Tests

- map spawn/resource/fairness validation;
- mode and player-count coverage;
- UI flow/usability tests;
- graphics/audio/VFX regression;
- content integrity и license registry checks;
- exact quality bars: TBD / Owner Decision Required.

## Risks

- map advantage и resource imbalance;
- content volume;
- presentation performance cost;
- unclear art/UX direction;
- third-party license risk.

## Out of Scope

- новые сложные map mechanics без необходимости;
- подфракции и post-1.0 modes;
- deep scale optimization Phase 8;
- campaign без approval.

## Definition of Done

Утверждённый 1.0 map/content/presentation scope существует в production quality, карты валидированы для заявленных modes, а assets и UX проходят согласованные проверки.
