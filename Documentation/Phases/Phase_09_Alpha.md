# Phase 09 — Alpha

> Status: planned • Milestone M6 Alpha

## Goal

Собрать полную цельную игру в Alpha-состоянии со всеми обязательными 1.0 pillars.

## Dependencies

- M3 Five Factions;
- M4 RTS AI;
- production maps/content/presentation baseline;
- M5 Scale Prototype;
- integrated multiplayer/reconnect foundation.

## Scope

- five factions;
- core gameplay;
- multiplayer;
- AI;
- maps;
- reconnect;
- replay;
- balance baseline;
- performance baseline.

## Key Systems

- цельный end-to-end game flow;
- faction/gameplay integration;
- multiplayer/reconnect/replay;
- AI и maps;
- balance/performance baselines;
- Alpha issue tracking и diagnostics.

## Milestones

- feature-complete Alpha по утверждённому 1.0 scope;
- M6 Alpha.

## Acceptance Criteria

- все перечисленные Alpha pillars интегрированы;
- пять основных фракций playable;
- multiplayer, AI, maps, reconnect и replay доступны в Alpha scope;
- balance/performance baselines зафиксированы;
- blocking Alpha criteria выполнены; точные thresholds — Owner Decision Required.

## Tests

- full regression suite;
- end-to-end mode/faction coverage;
- multiplayer/reconnect/replay tests;
- AI/map/content validation;
- performance and long-run baseline tests;
- Alpha acceptance matrix.

## Risks

- интеграционный defect backlog;
- неполная mode/faction coverage;
- нестабильный reconnect/replay;
- недостаточный balance/performance baseline;
- незафиксированные Alpha quality thresholds.

## Out of Scope

- Beta-level balance/polish/stress closure;
- Release Candidate feature freeze;
- post-1.0 content и подфракции.

## Definition of Done

Полная цельная игра включает пять фракций, core gameplay, multiplayer, AI, maps, reconnect, replay и documented balance/performance baselines; Alpha criteria приняты, M6 complete.
