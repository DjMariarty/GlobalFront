# Phase 12 — GlobalFront 1.0

> Status: planned • Milestone M8 Release 1.0

## Goal

Выпустить GlobalFront 1.0 в полном утверждённом Product Scope.

## Dependencies

- accepted Release Candidate;
- owner go/no-go;
- production deployment/server infrastructure;
- release/legal/support requirements — детали TBD / Owner Decision Required.

## Scope

- five main factions;
- full Generals/Zero Hour gameplay foundation;
- 1v1, 2v2, 3v3, 4v4, 5v5 и FFA;
- up to 10 players;
- AI;
- reconnect/resync;
- replay;
- desync detection;
- large armies и 3000+ target;
- multi-hour matches;
- production-quality graphics/UI/audio;
- stable server;
- balanced five factions.

## Key Systems

- complete product build;
- authoritative dedicated server;
- all gameplay/faction/AI/map/presentation systems;
- operations, diagnostics и release evidence;
- release notes and version record.

## Milestones

- production release approved;
- M8 Release 1.0.

## Acceptance Criteria

- каждый пункт approved 1.0 Definition of Done подтверждён;
- release candidate принят владельцем;
- server/deployment operational;
- known issues не нарушают approved release gates;
- release documentation и evidence complete.

## Tests

- final regression across five factions and all modes;
- 10-player/5v5/FFA validation;
- AI, reconnect/resync, replay and desync tests;
- 3000+ target and multi-hour stability evidence;
- production presentation and server validation.

## Risks

- расхождение release build и validated candidate;
- infrastructure/operations failure;
- неполный 1.0 scope;
- balance or scale regression;
- untracked licensing/release requirements.

## Out of Scope

- система 25 подфракций;
- новые factions и modes;
- advanced modding, ranked и spectator expansion;
- campaign без отдельного approval.

## Definition of Done

Пять основных фракций, полный gameplay foundation, все утверждённые modes, AI, reconnect/resync, replay, desync detection, scale/long-match targets, production presentation и stable server подтверждены; owner одобрил выпуск; M8 complete.
