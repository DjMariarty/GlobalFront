# Phase 10 — Beta

> Status: planned • Milestone M7 Beta

## Goal

Довести Alpha до Beta-quality по balance, stability, multiplayer, AI, performance, UX, maps, bug fixing и stress.

## Dependencies

- M6 Alpha;
- утверждённые Beta quality gates;
- complete issue triage и reproducible test environments.

## Scope

- balance;
- stability;
- multiplayer;
- AI;
- performance;
- UX;
- maps;
- bug fixing;
- stress.

## Key Systems

- regression/triage pipeline;
- balance validation;
- multiplayer and AI reliability;
- performance/stress suites;
- UX/map quality validation.

## Milestones

- Beta quality gate;
- M7 Beta.

## Acceptance Criteria

- утверждённые Beta blocking defects закрыты;
- multiplayer/AI/performance/stress соответствуют Beta gates;
- balance, UX и maps имеют принятый Beta baseline;
- regressions воспроизводимы и диагностируемы;
- точные severity/quality thresholds: TBD / Owner Decision Required.

## Tests

- full regression across modes/factions;
- balance and UX validation;
- multiplayer/AI/load/soak/stress suites;
- map coverage;
- defect-fix regression tests.

## Risks

- поздние systemic defects;
- balance churn;
- unstable stress results;
- UX/content fixes, создающие regressions;
- неясные Beta release gates.

## Out of Scope

- новые крупные features;
- post-1.0 systems;
- Release Candidate deployment/final validation.

## Definition of Done

Beta quality gates по balance, stability, multiplayer, AI, performance, UX, maps, bugs и stress выполнены; M7 принят.
