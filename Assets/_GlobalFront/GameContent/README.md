# GameContent

Здесь размещаются оригинальные игровые данные GlobalFront: определения юнитов и зданий, баланс, карты, материалы, prefab и собственные производные ассеты. Сторонние исходники в этой папке не хранятся.

Для общепроектных правил и статуса используйте [индекс документации](../../../Documentation/README.md). Лицензии внешних материалов фиксируются в [реестре сторонних ассетов](../../../Documentation/ThirdPartyAssetsRegistry.md).
