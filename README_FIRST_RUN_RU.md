# Первый запуск GlobalFront

> Unity: `6000.5.6f1` • текущая реализация: локальный технический RTS-прототип

## Открытие проекта

1. В Unity Hub выберите каталог `GlobalFront`, в котором находятся `Assets`, `Packages` и `ProjectSettings`.
2. Дождитесь завершения импорта и компиляции.
3. Откройте `Assets/Scenes/SampleScene.unity`.
4. Нажмите Play.

В Build Settings включена одна сцена — `SampleScene`. Мир и presentation-юниты создаются временным runtime bootstrap-кодом. Это не производственный контент пяти фракций.

## Управление текущим прототипом

- ЛКМ по дружественному юниту — выбрать юнит.
- Рамка с зажатой ЛКМ — выбрать группу.
- Shift + ЛКМ — изменить текущий выбор.
- ПКМ по земле — команда движения выбранной группе.
- ПКМ по живому вражескому юниту — команда атаки.
- WASD, стрелки или курсор у края окна — перемещение камеры.
- Колесо мыши — масштаб камеры.

Команды проходят через `ICommandChannel` в локальный authoritative `MatchServer`. Симуляция использует фиксированный шаг 20 Hz, но отдельного server tick driver, сетевого транспорта и удалённой сессии пока нет.

## Ограничения

- `LocalMatchHost` работает внутри клиентского процесса.
- Локальный игрок зафиксирован как `PlayerId(1)`.
- Pathfinding, transport, reconnect/resync, replay и desync detection ещё не реализованы.
- Временные препятствия не участвуют в детерминированном поиске пути.
- Фракции и производственный контент 1.0 пока являются утверждённым планом, а не текущей реализацией.

## Автоматические проверки

Откройте `Window → General → Test Runner`. Последние сохранённые результаты от 2026-08-12: **161/161 EditMode** и **5/5 PlayMode** тестов пройдены. После изменения runtime-кода проверки требуется запустить заново.
