# Первый запуск боевого прототипа GlobalFront

> Unity: `6000.5.6f1`
> Тип: локальный RTS-прототип

## Запуск

1. В Unity Hub откройте корень репозитория — папку, в которой расположены `Assets`, `Packages` и `ProjectSettings`.
2. Дождитесь завершения импорта и компиляции.
3. Откройте `Assets/Scenes/SampleScene.unity`.
4. Нажмите Play.

В Game View появятся полигон, синяя и красная армии, временные препятствия, полосы здоровья и диагностический HUD. Мир и юниты пока создаются runtime bootstrap-кодом, поэтому это не демонстрация готового контента.

## Управление

- ЛКМ по синему юниту — выбрать один юнит.
- Рамка с зажатой ЛКМ — выбрать группу.
- Shift + ЛКМ — добавить юнит к выделению или убрать его из выделения.
- ПКМ по земле — отправить выделенные юниты в построение и отменить текущую цель атаки.
- ПКМ по живому красному юниту — отдать выделенной группе команду атаки.
- WASD, стрелки или перемещение курсора к краю окна — перемещение камеры.
- Колесо мыши — масштаб камеры.

Команды ставятся в очередь на следующий тик и упорядочиваются как `RequestedTick -> PlayerId -> Sequence`. Локальная симуляция работает с частотой 20 Hz; полноценная авторитетная клиент-серверная синхронизация пока не реализована.

Красные юниты автоматически выбирают противника в ограниченном радиусе. Погибшие юниты не выбираются, не двигаются и не наносят урон. После завершения боя HUD показывает `VICTORY`, `DEFEAT` или `DRAW`.

Временное преследование идёт по прямой: обход препятствий и навигационная сетка ещё не реализованы.

## Автоматические тесты

Откройте `Window -> General -> Test Runner`, выберите `EditMode` и нажмите `Run All`. Базовая проверка от 08.08.2026 — **102/102 пройденных EditMode-теста**.

## Если появилась ошибка

Не исправляйте код вслепую. Откройте Console, выберите первую красную ошибку и сохраните её полный текст или скриншот для диагностики.
