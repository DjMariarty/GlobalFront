# Global Front - проверка боевого прототипа 0.3

Проект зафиксирован на Unity **6000.5.6f1**. Не открывайте его другой версией редактора.

## Запуск

1. Откройте корень проекта, содержащий `Assets`, `Packages` и `ProjectSettings`.
2. Дождитесь завершения импорта и компиляции.
3. Откройте `Assets/Scenes/SampleScene`.
4. Нажмите Play.

В Game View должны появиться полигон, синяя и красная армии, препятствия, полосы здоровья и диагностический блок `BATTLE PROTOTYPE 0.3`.

## Управление

- `ЛКМ` по синему юниту - выделить один юнит.
- Рамка с зажатой `ЛКМ` - выделить группу.
- `Shift + ЛКМ` - добавить или убрать юнит из выделения.
- `ПКМ` по земле - отправить выделенных юнитов в построение и отменить их текущую атаку.
- `ПКМ` по живому красному юниту - отдать выделенной группе команду атаки.
- `WASD`, стрелки или курсор у края окна - перемещение камеры.
- Колесо мыши - масштаб.

Команды ставятся в единую очередь на следующий тик и выполняются в порядке `RequestedTick -> PlayerId -> Sequence`. Движение, проверка дальности, перезарядка, урон и смерть разрешаются авторитетной симуляцией с частотой 20 Гц.

Красные юниты автоматически обнаруживают противника в ограниченном радиусе. Синие юниты после команды атаки продолжают искать ближайшую живую цель, пока не получат приказ двигаться. Урон всех готовых атак одного тика сначала собирается по единому снимку, затем применяется одновременно. Поэтому исход не зависит от порядка объектов, а взаимное уничтожение остаётся возможным.

После уничтожения одной армии HUD фиксирует `VICTORY`, `DEFEAT` или `DRAW`. Погибшие юниты больше не выбираются, не двигаются и не наносят урон.

На этом этапе преследование идёт по прямой: обход препятствий и полноценная навигационная сетка остаются отдельным этапом.

## Автоматические тесты

Откройте `Window -> General -> Test Runner`, выберите `EditMode` и нажмите `Run All`. Должны пройти тесты часов симуляции, заголовков и payload команд, построения, целочисленного движения, AttackCommand, дальности, перезарядки, агрегированного урона, взаимного уничтожения и исхода боя.

## Если появилась ошибка

Не исправляйте код вручную. Откройте Console, выберите первую красную ошибку и сохраните полный текст или скриншот.
